Changelog

v1.2.0 Latest stable
CHANGE
Migrated GUI from Tkinter → PySide6

The entire interface has been rebuilt using PySide6 (Qt6). This brings native-quality widgets, proper thread safety via Qt signals/slots, smoother scrollbars, and consistent rendering across all Windows versions. pip install PySide6 is now required instead of tkinter.

NEW
"Previous Versions" Button — Browse Version History

New Previous button next to the hash field. Fetches a list of recent versions from the WEAO API (https://weao.xyz/api/versions/past) with header User-Agent: WEAO-3PService. If the API is unavailable, falls back to parsing DeployHistory.txt from the CDN (up to 30 hashes). A popup dialog lets you pick and load any version with one click.

NEW
Desktop Shortcut Creation (opt-in)

A new checkbox "Create Desktop Shortcut after install" places a .lnk shortcut for the installed RobloxPlayerBeta.exe on the Desktop. Uses winshell if installed, otherwise falls back to a PowerShell script automatically.

NEW
Delete Installed Version from Disk

History rows now include a 🗑 button. Clicking it offers to remove the entry from history only, or to also delete the installation folder from disk (via shutil.rmtree).

NEW
Resumable Downloads (HTTP Range)

If a partial .part file exists from a previous interrupted download, the next run sends a Range: bytes=N- header to resume from where it left off, saving bandwidth. Handles HTTP 416 (range not satisfiable) by automatically restarting from byte 0.

IMPROVE
Concurrent CDN Probing

CDN selection now uses a ThreadPoolExecutor to probe all 5 endpoints simultaneously and pick the one that responds first. Previously probed sequentially, which added noticeable delay on startup.

IMPROVE
Options Panel — Three Configurable Checkboxes

The Options section now exposes three independent settings: (1) Register roblox:// protocol in Registry, (2) Install WebView2 Runtime silently, (3) Create Desktop Shortcut. All are remembered per-session.

IMPROVE
Thread-safe Signals via Qt Signals/Slots

Worker → UI communication now uses Qt's Signal / QThread mechanism instead of root.after(). This is the proper cross-thread update pattern for Qt and eliminates the risk of UI freeze or crash on rapid updates.

FIX
Unsafe Directory Guard Extended

The safety check now correctly allows subdirectories of C:\Program Files\Roblox while still blocking the root of C:\Windows, C:\, /, /usr, /etc, and other OS directories.

FIX
History Delete Shows Correct Prompt

If the installation folder no longer exists on disk, only a simple "Remove from history?" prompt is shown — no longer incorrectly asks about disk deletion for a folder that is already gone.

v1.1.0 Previous stable
NEW
Multi-CDN Fallback & Auto-Selection

Automatically checks 5 CDN endpoints and selects the server with the lowest latency to begin downloading.

NEW
Dual Progress Bar + Speed & ETA Display

Red bar for overall progress, purple bar per-package. Download speed and ETA updated every 400ms.

NEW
"Latest" Button, Installation History, roblox:// Protocol, WebView2, Background Music

All core features introduced in v1.1.0 — see previous documentation for full detail.

NEW

Download and extract Roblox Player packages from CDN by version hash. Basic Tkinter interface, sequential downloading, MD5 verification.

Quick Start

Just 3 steps to install any version of Roblox Player:

# 1. Install required libraries
pip install PySide6 requests pygame

# 2. Run the application
python RobloxVersionDownloader.py

# 3. Click "Latest" to fetch the hash, then click "⬇ INSTALL ROBLOX PLAYER"
✅

If you just want to install the latest version, click "Latest" — the app fills in the hash automatically. To browse older builds, click "Previous" and choose from the popup list.

Detailed Installation Guide

Installing Python & Libraries

  1. Download Python 3.10+

    Download from python.org/downloads. During installation, check ✅ "Add Python to PATH".

  2. Open Command Prompt / PowerShell

    Press Win + R → type cmd → Enter.

  3. Install required libraries

    Run: pip install PySide6 requests
    Optional: pip install pygame winshell

  4. Run the application

    Navigate to the folder containing the file and run: python RobloxVersionDownloader.py

Installing Roblox Player

  1. Select a Version Hash

    Click "Latest" to fetch the newest hash, "Previous" to browse older builds, or manually type a known hash.

  2. Confirm the installation directory

    Default: %LOCALAPPDATA%\Roblox\Versions\. Click "📁 Browse..." to change it. System folders are blocked for safety.

  3. Configure install options

    In the OPTIONS panel, choose which extra steps to perform: register the roblox:// protocol, install WebView2 silently, or create a Desktop shortcut.

  4. Start installation

    Click the red "⬇ INSTALL ROBLOX PLAYER" button. The app probes all CDNs in parallel, downloads the manifest, then streams each package with live progress.

  5. Wait for completion

    Monitor the dual progress bars and log. Once finished, a dialog asks if you want to open the installation folder.

ℹ️

The cache folder (%LOCALAPPDATA%\Roblox\Downloads\) stores downloaded .zip files. If a download is interrupted, it resumes from the last byte on the next run — no wasted bandwidth.

Version Hash

A version hash is the unique identifier of each Roblox Player release. The application uses this hash to access the correct manifest and download the correct set of installation files.

Valid Format

✅ VALID

version-eb4648e9148d440c
eb4648e9148d440c (prefix auto-added)
16 hex characters after the -

❌ INVALID

version-abc123 (fewer than 16 characters)
1.2.3.4567 (version number format)
Hash containing non-hex characters

How to Find a Hash

  1. Fastest — "Latest" button

    Click the button in the app. The Roblox API returns the current hash automatically.

  2. Browse older versions — "Previous" button

    Opens a scrollable list fetched from the WEAO past API or CDN's DeployHistory.txt as fallback. Select any entry to load it instantly.

  3. Directly via Roblox API

    Visit: https://clientsettingscdn.roblox.com/v2/client-version/WindowsPlayer — the clientVersionUpload field contains the hash.

  4. From an existing Roblox installation

    Open %LOCALAPPDATA%\Roblox\Versions\ and look at the subdirectory names — those are the hashes.

Install Options

Three checkboxes in the OPTIONS panel let you customize what happens after the packages are extracted.

OptionDefaultDetails
Register roblox:// protocol ✅ On Writes HKCU\Software\Classes\roblox and roblox-player registry keys so browsers can launch Roblox games directly. Requires winreg (Windows only).
Install WebView2 Runtime ☐ Off Extracts WebView2RuntimeInstaller.zip and runs the .exe with /silent /install. Enable this only if WebView2 is not already installed on the system.
Create Desktop Shortcut ☐ Off Creates a Roblox version-xxxx.lnk shortcut on the Desktop pointing to RobloxPlayerBeta.exe. Uses winshell if available, otherwise falls back to a PowerShell command.
ℹ️

Options are applied at the end of installation, after all packages are extracted. Cancelling mid-way will not apply any options even if the checkboxes are enabled.

Installation History

Each successful installation saves its information to download_history.json in the same directory as the script. Up to 20 entries are stored; the most recent is always at the top.

ButtonFunction
↺ (Reload)Fills the version hash into the input field to reinstall the same version
📂 (Open folder)Opens the installation folder for that version in File Explorer
🗑 (Delete)Removes the entry from history. If the folder exists on disk, prompts to also delete it permanently.
⚠️

Deleting via the 🗑 button is permanent. Files deleted this way are not moved to the Recycle Bin — they are removed with shutil.rmtree. Make sure you no longer need the installation before confirming.

Troubleshooting

"ModuleNotFoundError: No module named 'PySide6'"

v1.2.0 now requires PySide6 instead of tkinter

Run pip install PySide6 in your terminal. If you have an older environment, you may need to upgrade pip first: python -m pip install --upgrade pip.

"Version Not Found" — Hash does not exist on CDN

Cause & Solution

The hash is incorrect or the version has been removed from the CDN. Use the "Previous" button to browse valid hashes, or "Latest" for the current build.

"Connection Lost" — ConnectionError

Cause & Solution

Check your Internet connection. If interrupted mid-download, simply click Install again — the download will resume automatically from the last byte. Firewalls or VPNs can block Roblox CDNs; try disabling or changing DNS (8.8.8.8).

"Checksum Failed" — MD5 mismatch

Cause & Solution

The file was corrupted during download. The app deletes the bad cache file automatically. Run Install again to re-download from scratch.

"Write Permission Error" — PermissionError

Cause & Solution

The install directory has restricted permissions. Try running as Administrator, or choose a different directory where your user account has write access.

Desktop shortcut was not created

Cause & Solution

Verify that RobloxPlayerBeta.exe was extracted correctly (i.e., installation completed without error). If winshell is not installed, the app uses PowerShell as a fallback — make sure PowerShell execution policy allows scripts, or install pip install winshell.

Music does not play — pygame error

Cause & Solution

Check: 1) pip install pygame has been run. 2) sound/music.mp3 exists. 3) The audio driver is working. Music is optional and does not affect installation.

💡

When encountering an error, read the Log window carefully — each message is color-coded and includes a description of the cause and a suggested resolution.

Frequently Asked Questions

Is the application safe?

The application only downloads files from Roblox's official CDN (setup.rbxcdn.com and its subdomains). No data is sent to any external server. The full Python source code is open for review.

How is this different from a normal Roblox installation?

Roblox's official installer always installs the latest version and doesn't allow choosing a specific one. This tool lets you install any version by hash — useful for rolling back or testing a specific build.

Where is the cache? Can I delete it?

Cache is at %LOCALAPPDATA%\Roblox\Downloads\. Safe to delete when no longer needed. Reinstalling will re-download (and resume if connection drops).

Can multiple versions be installed at the same time?

Yes. Each version creates its own subdirectory named after its hash under the Versions folder. Install version A, change hash to B, install again — both coexist.

The roblox:// protocol doesn't work after installation?

The registry key is written to HKCU\Software\Classes\roblox. Restart your browser after installation. If it still doesn't work, verify RobloxPlayerBeta.exe exists in the install folder and the "Register roblox:// protocol" checkbox was enabled.

Why did you switch from tkinter to PySide6?

PySide6 provides proper thread-safe signal/slot communication between the worker thread and the UI, native Qt widgets with reliable styling, and better cross-platform rendering. tkinter's root.after() workaround was functional but not idiomatic for multi-threaded applications.

Does it work on Mac / Linux?

The download and extraction code is cross-platform. However, Roblox's .exe files only run on Windows, so installing on macOS/Linux has no practical use. Registry and shortcut features are silently skipped on non-Windows systems.
